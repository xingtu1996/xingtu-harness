## 7. 如何改善（三个最重要问题）

### 问题 A：跨会话/跨 Agent 上下文丢失
- **最小改进动作**：每条任务产出统一 Receipt 文件（Goal/Trigger/Capability/Receipt + 来源哈希 + 状态），落盘到交接中心目录；本报告即按此契约执行。
- **可验证指标**：重复提问次数 / 任务完成率 / 证据可追踪率（issue #5 已列度量）。
- **预期解决的障碍**：跨 Agent 接力断点、你反复补充上下文的成本。

### 问题 B：推测冒充事实 / 空泛规划冒充执行
- **最小改进动作**：交付物强制证据分级标注（有证据/用户陈述/推测/未知），未验证项显式标 NOT_RUN；规划与产出分开记录。
- **可验证指标**：报告内「推测/未知」占比、返工率、验收一次通过率。
- **预期解决的障碍**：误信导致的错误决策、返工与信任损耗。

### 问题 C：工具链路静默失败与定时冲突
- **最小改进动作**：管线脚本移除 `2>/dev/null` 静默吞错模式、失败即告警；定时任务与草稿通道冲突排查清单化（发布前检查 53407 类占用）。
- **可验证指标**：发布链路故障次数、失败从发现到修复的时长、告警漏报数。
- **预期解决的障碍**：发布阻塞、过期数据污染判断（如 bsk 沿用旧快照）。
